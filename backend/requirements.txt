# PyBullet is the primary validation oracle (Phase 0-3): ships UR5/Panda URDFs,
# built-in FK (getLinkState), real self-collision (getClosestPoints), and a
# native IK baseline. Pure pip, runs headless on Windows. Optional at import
# time — the sim/ package degrades gracefully and its pytest skips if absent.
pybullet>=3.2,<4.0 ; python_version < "3.13"
# NOTE: pybullet has no cp313 Windows wheel as of 2026-07; on Python 3.13 it
# must be built from source (needs MSVC) or run under a 3.11/3.12 venv. See
# backend/app/sim/README.md for the fallback. The marker above keeps a clean
# `pip install -r requirements.txt` from failing on 3.13 where no wheel exists.
#
# MuJoCo is the Phase-4 second oracle (cross-checks PyBullet FK + collision on the
# identical URDF). It ships prebuilt Windows wheels (no compiler), so it can live in
# .venv-sim alongside pybullet OR — because it needs no compiler — directly in the
# core venv, which is how the native live viewer (app/sim/live_viewer.py) runs.
mujoco>=3.2,<4.0 ; python_version < "3.13"
# robot_descriptions resolves & caches the UR5/Panda URDFs (pure Python, no compiler)

# the URDF's .dae visual meshes to .obj so MuJoCo can render them).
